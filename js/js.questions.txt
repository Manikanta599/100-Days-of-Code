What is strict mode?
Strict Mode is a JavaScript feature that enforces stricter rules to help developers write safer and cleaner code. It is enabled by adding "use strict"; at the top of a file or function. It prevents common mistakes like creating undeclared variables, disallows duplicate parameter names, changes some unsafe behaviors into errors, and makes debugging easier. In modern JavaScript, ES Modules and classes run in strict mode automatically.
